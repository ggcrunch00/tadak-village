학급 로그인 관리

학생은 게임 첫 화면에서 학급 코드 + 번호 + 그림 비밀번호(동물 하나, 과일 하나)로 로그인해요. 같은 학급 코드로 이 관리 사이트에 연결된 모든 게임에 들어갈 수 있어요.

학생 이름은 수집하지 않아요. 서버에는 학급 이름, 학생 번호, 그림 비밀번호, 게임 기록만 저장돼요. 아래 표에 적는 학생 이름은 이 컴퓨터의 브라우저에만 저장되고 서버로 보내지 않아요. 다른 컴퓨터에서는 이름 대신 번호만 보여요. 개인정보 처리방침

서버가 연결되지 않았어요

이 사이트와 같은 폴더의 server.json에 Supabase 주소와 공개 키를 넣어야 해요. 설정 방법은 SETUP.md를 봐 주세요.
