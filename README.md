# 타닥타닥 마을

타자로 자원을 모아 섬마을을 짓고, 말결 군도의 이름을 되찾는 싱글플레이 타자 연습 시티빌더예요.
서버 없이 브라우저 하나로 돌아가는 단일 HTML 게임이에요.

## 바로 배포하기
`dist/index.html` 하나만 올리면 돼요. 외부 파일 의존은 Google Fonts뿐이고, 그림과 아이콘은 모두 파일 안에 들어 있어요.

- **GitHub Pages / Netlify / Vercel:** `dist/index.html`을 정적 사이트 루트에 올리기
- **itch.io (HTML5 게임):** `dist/tadak-village-web.zip`을 업로드하고 "This file will be played in the browser" 선택. 권장 화면 1280×800, 전체 화면 버튼 켜기
- **로컬:** `dist/index.html`을 브라우저로 열기

저장은 브라우저 `localStorage`에 돼요(기기별 저장). 서버 저장과 계정은 이후 작업으로 남겨 뒀어요.

## 구성
| 파일 | 내용 |
|---|---|
| `src.html` | 게임 원본 (HTML, CSS, JS) |
| `build.py` | 아이콘과 그림 데이터를 합쳐 `index.html`(아티팩트용)과 `dist/`(배포용)를 만듦 |
| `assets/` | 아이콘 맵, 잘라 낸 스프라이트(json), 생성 원본 이미지 |
| `tools/` | 이미지 자르기(`slice_sheet.py`), 마젠타 배경 지우기(`key_magenta.py`) |
| `parts/` | 캠페인 데이터와 엔진의 원본 조각 (이미 `src.html`에 합쳐져 있음) |
| `STORY.md` | 세계관, 인물, 6장 캠페인 |
| `DESIGN.md` | 디자인 진단, 토큰, 그래픽 메모 |
| `ROADMAP.md` | 완료한 것과 다음 할 일 |

빌드:
```bash
python3 build.py
```

## 게임 모드
- **캠페인:** 6장. 장마다 섬 모양, 목표, 인물, 이벤트가 달라요. 별 최대 18개.
- **자유 모드:** 제한 없이 마을을 키우는 모드. 의뢰, 업적, 오늘의 연습, 주민 부탁.

## 마을이 커지면
- 명성 등급: 빈 터 → 작은 마을 → 아늑한 마을 → 활기찬 마을 → 번화한 마을 → 타닥 시티. 등급마다 모든 보상 +4%와 새 건물, 아침 세금, 축제가 열려요.
- 생산 건물(벌목소, 채석장, 벽돌 가마, 필사실)은 주민이 일손으로 들어가야 돌아가요. 집을 지어 주민을 늘려요.
- 마을 이름표(왼쪽 위)를 누르면 등급, 혜택, 일손, 세금, 축제를 한눈에 볼 수 있어요.

## 선생님 설정
- **글감 주제:** 섞기 / 미덕 / 교과(5~6학년 사회·수학 중심) / 마을 이야기
- **난이도:** 쉬움(보상 1.35배) / 보통 / 어려움(보상 0.75배)
- 교과 글감은 선생님 자료 폴더의 단원 용어를 바탕으로 새로 쓴 문장이에요(교과서 문장을 그대로 옮기지 않았어요).

## 조작
- 단어/영단어: 치고 `Space` · 문장/긴 글: 끝까지 치고 `Space` 또는 `Enter`
- `Tab` 모드 바꾸기 · `Esc` 취소/설정 · `Ctrl+Z` 방금 지은 건물 되돌리기
- 건물 클릭: 옮기기, 철거 · 마우스 드래그: 지도 이동 · 휠 또는 오른쪽 +/− 버튼: 확대/축소
